# Portfolio

Personal portfolio of Antoine Bernard: a single self-contained `index.html` with links to
my CV, email, LinkedIn, GitHub and Linktree.

No build step and no dependencies. Open `index.html` in a browser, or serve the folder with
any static host.

```bash
python3 -m http.server 8000
```

Images and fonts are inlined into the page, which is why the file is large (about 3 MB).
